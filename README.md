## ▶️ How to Run the Programs

1. Install GCC or MinGW and configure it in your system PATH.

2. Clone this repository:

   ```bash
   git clone https://github.com/omkar09-hub/c-programming-practice.git
   ```

3. Open the project folder in VS Code.

4. Open the terminal in the folder containing your C file.

5. Compile a program:

   ```bash
   gcc Program1.c -o Program1
   ```

6. Run the program on Windows:

   ```bash
   Program1.exe
   ```

Replace `Program1.c` with the filename you want to run.

**Note:** If a program uses a separate header or source file, you may need to compile all required source files together.
